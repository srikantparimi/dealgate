## Tokens & tests

- Colour, typography, radius, spacing, breakpoint tokens live in
  `web/src/index.css` (CSS vars) and `web/tailwind.config.ts` (Tailwind
  colour extensions + font sizes). `web/src/__tests__/ui-v2/tokens.test.ts`
  fails whenever a token drifts from `DealGate_Design_Tokens_v2.1.json`.
- Computed-style / structural checks on the primitives live in
  `web/src/__tests__/v2/design-tokens.test.tsx`.
- Colour rule enforcement: `web/src/__tests__/ui-v2/no-hex.test.ts` grep
  bans arbitrary hex codes in shipped components.
