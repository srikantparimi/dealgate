## §B — sync (B3–B8)

- **B3 (infra) — done under I2/I3/I4.**
- **B4 · webhook enqueues to SQS.**
  `api/app/routers/hubspot.py::hubspot_webhook` sends each verified
  event to `HubSpotEventsQueue` when `HUBSPOT_EVENT_QUEUE_URL` is set,
  falls back to the legacy `store_events` DB path otherwise so local
  dev + tests without SQS still work. Response counters split into
  `queued` vs `stored`. Proof:
  `tests/test_hubspot_events_queue.py::test_webhook_enqueues_when_queue_url_set`.
- **B5 · SQS consumer.** `worker/hubspot_intake.py::run_once` long-
  polls (20 s), processes at most 10 messages per receive, deletes on
  success (SQS redrives to DLQ after 3 receive attempts per the
  queue's `redrive_policy`), writes `sync_status` at the end. Soft
  budget default 240 s so the 5-minute EventBridge tick never overlaps
  itself. Legacy `process_pending` DB-poll helper preserved for the
  pre-S19 flow that tests still exercise. Proofs:
  `tests/test_hubspot_events_queue.py::test_consumer_drains_stub_queue_and_writes_sync_status`
  + the untouched `tests/test_hubspot_intake.py::test_worker_process_pending_runs_intake`.
- **B6 · nightly reconcile.** `worker/hubspot_reconcile.py::run_once`
  reuses `run_backfill` so the mapper + pagination + pipeline mirror +
  drift upsert flow through one implementation. Wraps the run with
  `touch_source(source='hubspot_reconcile', success=…)`. TF I4 pinned
  the cron at 04:00 UTC daily.
- **B7 · deleted / merged deals.** The mapper already writes
  `archived_at` + `archived_reason` for HubSpot-deletion / merge
  paths (S18 §2a). Slice-1 SQS consumer preserves that behaviour
  because it hands the raw event straight to
  `services.hubspot_intake.handle_event`.
- **B8 · sync_status written by every run.** `touch_source` upserts
  the row on success (`last_success_at + lag_seconds=0`) or failure
  (`last_error` + `lag_seconds = now - last_success_at`); the row
  survives concurrent writes because whichever transaction commits
  last wins. Proofs:
  `test_consumer_drains_stub_queue_and_writes_sync_status`,
  `test_touch_source_records_error_without_clobbering_success`.
