## Implementation

- Five permanent approval groups in Settings / People & access / Groups.
  Delivery, HR, Finance and Legal have editable membership, default and backups.
  Executive reflects existing CEO membership and time-bound delegation.
- Submission pins the current confirmed SOW and complete GM versions, validates
  group membership, excludes the submitter, and requires distinct functional
  reviewers. Empty groups remain empty and produce admin-owned routing blockers.
- Assigned tasks, notifications and review deep links follow the existing
  Delivery + HR, Finance + Legal, then conditional CEO order. Later-stage
  reviewers receive submission notifications; actionable tasks activate at their
  stage. Default SLA dates restart at activation (two business days); manually
  selected dates are preserved. Owners/admins can route newly configured groups.
- Decisions require a reason. Current group membership and assignment are checked
  server-side. A package row lock serializes parallel decisions. Decided,
  rejected and voided packages complete/cancel their workflow tasks; generic task
  controls cannot bypass approval decisions or reassign review ownership.
- The Approvals tab displays package/version history, named actors, reasons,
  assignment due dates/age, CEO state and condition evidence. It refreshes every
  20 seconds while open. Board cards, command center, readiness and My Work use
  the same pending-with projection and functional decisions.
- The header always has a state-derived primary action. Scope confirmation now
  actually stamps `SowVersion.confirmed_at` and `confirmed_by` atomically after
  essential scope validation. Previously the confirmation route changed only the
  opportunity status, leaving the workspace in contradictory draft state.
- Scope completion does not require GM completion. Missing financial inputs lead
  to Staffing & GM; missing NDA/MSA permits review but blocks signature upload and
  release. CEO expiry and unmet condition evidence also gate signature.
- Human SOW title, owner name, breadcrumb, engagement/delivery values and extracted
  term replace identifier-based header text. Mobile layout has no horizontal
  overflow. Command-center routing owners wrap instead of being clipped, and
  frozen GM versions no longer incorrectly read as "GM not built".
