## Implemented

- Removed legacy page implementations and Legacy navigation. The old SPA
  URLs `/tasks`, `/deals`, `/deals/:id`, `/gm/sandbox`, `/margin-lab` render
  a friendly 404 view with a replacement-workspace link. This is an SPA
  not-found view, not a claim that the static host returns HTTP 404.
- Navigation has the twelve requested destinations, subject to existing
  Settings role visibility. In-app links now target the current workspace.
- NDA/MSA tracking is per legal entity, with owner and next action. Historical
  review states remain stored unchanged and display as tracking states.
  Expiring/expired status derives from dates, including legacy date fields.
- Legal/SystemAdmin can upload PDF/DOCX through the shared text extraction,
  OCR fallback and schema-validated Bedrock extraction path. Dates and source
  locators are pre-filled. Explicit signed-document/entity attestation is
  required; corrected dates require a reason. Hash dedupe and row locks guard
  repeated filing. Stored drafts retain evidence, extraction provenance and
  audit history. Executed files/dates cannot be bypassed through CRUD PATCH.
- SOW intake and existing HubSpot intake create idempotent obtain-NDA/MSA
  tasks for the account owner. Tasks link to their legal entity and close when
  coverage is filed. HubSpot task audits retain event correlation IDs.
- Missing coverage no longer blocks functional review. Signature upload URL,
  signed-upload registration and release enforce the shared coverage gate.
- Projects reads released approval packages and their pinned SOW/GM versions,
  with staffing resources and approved versus latest forecast GM. No rates or
  costs are returned by the new read model. Existing leader/owner scope is
  enforced server-side. Actuals/import/reconciliation data and APIs remain.
- Terraform grants the API task read/write access only to `agreements/*` and
  supplies `AGREEMENTS_BUCKET`. No hand-applied permissions or ECS changes.
