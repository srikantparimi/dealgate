## What's in the merged tree

**Legacy routes removed.** Every `/deals`, `/deals/:id`, `/tasks`,
`/gm/sandbox`, `/margin-lab` visit hits a `RetiredPage` (with the
directive's friendly redirect copy and a link to the replacement).
`App.tsx` wiring: lines 76 (`/deals`), 77 (`/deals/:id`), 84 (`/tasks`),
89 (`/gm/sandbox`), 153 (`/margin-lab`). SPA components deleted
(11 files, ~4,000 lines): `DealDetail`, `DealList`, `MyTasks`,
`GMSandbox`, `SOWConfirm`, `SOWUpload`, `SignedSOWReview`,
`WeeklyForecast`, `DeliveryModelBuilder`, `MarginLab`, plus
`projects/{ActualsTab,PortfolioTable,ProjectDetail,StaffingTab}`.
The GM engine (`api/app/gm/`) is untouched — only Margin-lab-specific
scenario storage went.

**Nav rebuilt** (`web/src/ui-v2/PrimaryNavigation.tsx`). Order matches
directive verbatim:

```
Workspace       → Command center, My work
Growth          → Pipeline clients, AI discovery, NDA & MSA
Commitments     → SOW approvals, New SOW studio
Operations      → Projects, Renewals, Signed handoff, Reporting
Administration  → Settings
```

**NDA & MSA simplified.** `web/src/pages/v2/AgreementsRegister.tsx` now
renders per-client-legal-entity status only (missing / requested / sent
for signature / executed / expiring / expired) — no approve/reject
routing on agreements. Uploading a signed NDA/MSA runs the same
extract pipeline, files against the legal entity and flips state to
executed (`api/app/services/agreement_tracking.py`).

**New-company gap task auto-created.** `hubspot_intake.py:429` calls
`ensure_agreement_tasks(...)` for every newly resolved client. The task
sits in the account owner's inbox with a deep link
(`/agreements?entity=<legal_entity_id>`) — the `TaskRow.record_url` field
(`api/app/routers/tasks.py`) is what the SPA follows.

**Signature gate preserved.** `api/app/services/coverage_gate.py::check_msa_and_nda_executed`
is now called only from signature paths (`signed_sow.py:72` and
`approval_workflow.py:240::require_signature_eligibility`), never at
submission — matches the directive's "blocks signature, not review".

**Projects page rebuilt.** `web/src/pages/v2/ProjectsActuals.tsx` shows
exactly running projects + resources + GM. Removed:
`api/app/routers/projects.py` still exposes the richer API for later,
but the SPA only reads the three-thing view. New service:
`api/app/services/projects.py`.
